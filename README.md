# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment data in India using Python.
The analysis focuses on data cleaning, exploratory data analysis,
visualization, COVID-19 impact, regional differences, and monthly
unemployment patterns.

## Objectives

- Analyze unemployment rate data
- Clean and preprocess the dataset
- Visualize unemployment trends
- Analyze the impact of COVID-19
- Compare rural and urban unemployment
- Analyze regional differences
- Identify monthly patterns

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data Cleaning
- Exploratory Data Analysis
- Unemployment Trend Analysis
- COVID-19 Impact Analysis
- Rural vs Urban Analysis
- Regional Analysis
- Employment Analysis
- Labour Participation Analysis
- Monthly Pattern Analysis
- Correlation Analysis

## Files

- `unemployment_analysis.ipynb` — Complete analysis notebook
- `cleaned_unemployment_data.csv` — Cleaned dataset

## Conclusion

This project demonstrates how Python-based data analysis and
visualization can be used to explore unemployment patterns in India
and examine changes during the observed period.
